# Security policy

## Supported versions

Security fixes are provided for the latest published release.

## Reporting a vulnerability

Please do not open a public issue for a vulnerability. Use
[GitHub's private vulnerability reporting](https://github.com/Udovychenko-Dmytro/lidless/security/advisories/new)
and include the affected version, reproduction steps, impact and any suggested
mitigation.

Lidless deliberately changes persistent power-management settings and includes
an optional narrowly scoped privileged helper. Reports involving privilege
boundaries, command execution, unsafe file handling, display recovery or failure
to restore system settings are treated as security-sensitive.
