# Changelog

All notable changes to Lidless are documented here. Versions follow Semantic
Versioning.

## [0.1.0] - 2026-08-11

First public release.

### Added

- Native macOS status window and menu bar controls.
- Closed-lid keep-awake support without an external monitor.
- Shared command-line interface through `lidless.sh`.
- Optional Low Power Mode, screen-lock relaxation and automatic shutdown.
- Built-in display blackout with a mandatory recovery watchdog and rescue tool.
- Battery, power, temperature and fan telemetry where the hardware exposes it.
- Universal Apple Silicon and Intel application bundle.
